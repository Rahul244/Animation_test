# The Wolf & The Little Duckling

A small animated, GitHub Pages-ready story page.

## Preview locally
Open `index.html` in a browser. Keep `storyboard.png` in the same folder.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `wolf-and-duckling`).
2. Upload both `index.html` and `storyboard.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder, then Save.
6. After GitHub finishes publishing, your site URL will appear in the Pages section.

The page is responsive and includes autoplay, pause, and restart controls.
